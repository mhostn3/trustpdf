About

TrustPDF is a privacy-first, client-side PDF tool, released as open source under the AGPLv3 license.

It lets you merge, split, rotate, reorder, and clean up PDF documents directly in your browser
with no uploads, no accounts, no cookies.

🙋‍♂️ Author

My name is Martin Hostnik. I am a civil engineer specialized in geotechnical and hydraulic engineering, with professional experience in advanced geotechnical design, numerical analysis, tunnel engineering, and soil-structure interaction.

Besides engineering, I also have a strong interest in software development, especially privacy-focused, browser-based tools built with Python, Django, JavaScript, and open-source technologies.

www.TrustPDF.net was created as a simple and transparent alternative to online PDF tools that require file uploads. The goal is to make common PDF tasks available directly in the browser, without accounts, storage, or unnecessary tracking.

🚀 Features

  • 🔒 100% client-side PDF processing — your files never leave your device
  • 📎 Merge multiple PDFs into one
  • ✂️ Split a PDF, or extract pages using ranges (e.g. 1-3,6,9) or a visual page picker
  • 🔄 Rotate, reorder, and remove pages with live thumbnails
  • 🏷️ View, edit, or completely strip PDF metadata (including hidden XMP data)
  • 🖼️ Convert JPG and PNG images into a PDF
  • 📱 Optimized for mobile and desktop use
  • 🧭 No login, no storage, no cookies, no third-party CDNs — fully private
  • 🧩 Built with pdf-lib, PDF.js, Bootstrap 5, and SortableJS

🛠 Tech Stack

  • HTML5
  • Bootstrap 5
  • pdf-lib (PDF processing)
  • PDF.js (page previews)
  • SortableJS
  • Django (for static file delivery and routing)
