Adding a password to a PDF is the simplest way to make sure only the right person can read it: a payslip for your accountant, a contract for a client, medical results for a family member. You do not need Adobe Acrobat or any paid software, and you do not need to upload the document to a website to do it.

How to add a password to a PDF

  1. Open Protect PDF and drop your file into the box.
  2. Type the password that will be needed to open the file, and type it again to confirm.
  3. Optionally, choose what readers may do: print, copy text, or edit. Set an owner password if you want to be able to change those permissions later.
  4. Click Protect PDF and save the encrypted file.

The file is encrypted with AES-256, the strongest encryption in the PDF standard and the same one Adobe Acrobat uses. Encryption happens in your browser with qpdf, an open-source PDF library, so neither your file nor your password is ever sent anywhere. Every current PDF reader, including the ones built into browsers, phones and macOS, can open it with the password.

Open password and owner password: what is the difference?

  • The open password (also called the user password) is needed to open the file at all. It is what actually encrypts the content. Without it, the PDF is unreadable.
  • The owner password controls the permissions: printing, copying and editing. Someone with only the open password can read the document, but their PDF reader is told not to allow the restricted actions.

Permissions are a polite request to the PDF reader, not real protection: some programs ignore them. If something must stay confidential, rely on the open password, not on "no copying".

Choosing a strong password

AES-256 cannot be broken by brute force, but a weak password can simply be guessed. Attackers try dictionary words, names, dates and common patterns first.

  • Use at least 12 characters, or better, three or four random words, such as lantern-orbit-cactus-mild.
  • Do not use your name, birthday, company name or the document's subject.
  • Store it in a password manager. If you forget it, nobody can recover the file, not even TrustPDF.

Sending the password safely

Never put the password in the same email as the file. Send it another way: a text message, a messenger app or a phone call. Anyone who gets both together, for example by gaining access to the mailbox, can open the PDF.

Before you protect a PDF

  • Clean up its metadata with the Metadata Editor if the recipient should not see the author or company.
  • Compress it first if it is too big to email; an encrypted file cannot be compressed afterwards without the password.
  • Keep an unprotected copy in a safe place if you may need to edit it.

Removing a password later

If you know the password, Unlock PDF saves a copy that opens without it, and also lifts printing and copying restrictions. It does not crack passwords you do not know.
