A PDF carries more than its pages. Hidden in the file there is usually a small record about the document: who wrote it, which company they work for, which programs made it, and when it was created and last changed. That is called metadata. Before you send a CV, a report, a legal document or anything you publish anonymously, it is worth checking what it says, and removing it.

What PDF metadata can reveal

  • Author: often your full name, taken automatically from Word or from your computer's user account.
  • Title and subject: sometimes a working title you never meant to share, such as "Draft v7 – do not send".
  • Creator and producer: the programs and versions used, for example Microsoft Word for Microsoft 365, or a scanner's software.
  • Creation and modification dates: exact to the second, which can contradict the date on the letter.
  • Keywords and sometimes the company name.

The part most tools miss: XMP

PDFs can store metadata twice. The classic "document properties" are what most viewers show and most editors let you change. Many programs also embed an XMP block, a separate XML record that can repeat the author and title, and add edit history, software details and more. Clearing the visible properties leaves the XMP block untouched, so the author's name can still be in the file.

Step 1: see what your PDF contains

  1. Open the PDF Metadata Viewer and drop your file into the box.
  2. Click View Metadata.
  3. Read the fields, and look at the line that says whether an XMP metadata stream is present.

Step 2: remove it

  1. Open the PDF Metadata Editor and drop in the same file. The current values are filled in.
  2. Click Clear all fields. To set a neutral title instead, type it in the Title field.
  3. Keep Also remove the embedded XMP metadata stream ticked.
  4. Click Update Metadata and save the cleaned PDF.

Open the saved file in the viewer again to confirm that the fields are empty and no XMP block is left. The pages themselves are not changed at all. Both tools run in your browser, so the file you are cleaning is never uploaded.

Other places a PDF can give you away

  • The visible content: names in headers, footers, signatures and stamps. Remove them properly with Redact PDF, as explained in how to redact a PDF.
  • Comments and tracked changes exported from Word. Accept or delete them in Word before you export the PDF.
  • The file name, which travels with the file.
  • Images pasted in from a phone can carry their own camera data inside the PDF. If that matters, compress the PDF with the Strong setting in Compress PDF, which redraws every page as a new image.

When you want metadata

If you publish a PDF on a website, a clear Title helps: search engines can show it as the result title instead of the file name. Use the editor to set a good title and leave your personal details out.
