Redacting a PDF means removing information before you share it: a name in a court filing, an account number on a bank statement, a patient's details in a report. Done wrong, it is one of the most embarrassing mistakes in document handling, because the "hidden" text can be copied straight back out. This guide shows how to do it properly, for free, without sending the unredacted file to anyone.

Why a black box is often not a redaction

Most PDF editors, and many online PDF sites, let you draw a filled black rectangle or highlight text in black. That looks like a redaction, but the rectangle is only a shape drawn on top of the page. The text underneath is still in the file. Anyone can select it, copy it and paste it into a text editor, or extract it with any PDF-to-text converter.

This has caught out lawyers, governments and large companies. In a well-known case from 2019, a court filing in a high-profile US trial was "redacted" with black bars; reporters simply copied the text from under them. The same thing happens every year with leaked reports and contracts.

Rule of thumb: a proper redaction removes the content under the box from the file. A cover-up only hides it on screen.

Why not use an online redaction service?

Redaction exists because a document contains something that must not be seen. Uploading the unredacted original to a free website sends exactly that information to a server you know nothing about, where it may be stored, logged or backed up. That defeats the purpose.

TrustPDF's Redact PDF runs entirely in your web browser. The file is read from your disk into the page, processed by JavaScript on your device and saved back to your disk. It is never sent anywhere, and you can check that yourself.

How to redact a PDF, step by step

  1. Open Redact PDF and drop your file into the box, or click it to choose the file.
  2. Drag rectangles over everything you want to hide: names, addresses, signatures, account numbers, photos.
  3. To find text automatically, type a word or number and click Find and mark. Use the email and phone buttons to mark every email address or phone number in the document.
  4. Go through every page with the arrows. Remove a box you placed by mistake with its × button.
  5. Click Redact PDF, then save the redacted file under a new name. Keep the original somewhere safe.

Every page with at least one box is rebuilt as an image with the black boxes burned in, so the text, images and layers under the boxes are not in the new file at all. Pages without boxes are copied unchanged. The document's metadata (title, author, dates) is left out too.

Check the result

Never send a redacted document without checking it. Two quick tests:

  • Select and copy: open the redacted PDF, press Ctrl+A (Cmd+A on a Mac), copy, and paste into a text editor. The hidden words must not appear.
  • Search: press Ctrl+F and search for a name or number you redacted. It must not be found.

You can also run the file through PDF to Text and read what is left.

Things people forget to redact

  • Metadata. The author field often holds a full name and the company. Check it with the Metadata Viewer and clear it with the Metadata Editor. Read more in how to remove metadata from a PDF.
  • Headers and footers that repeat a name or case number on every page.
  • Signatures and stamps, which are often images rather than text, so a text search will not find them.
  • The file name itself, such as Smith_divorce_settlement.pdf.

What about scanned documents?

A scanned page is already a picture, so text search cannot find anything on it. Draw the boxes by hand over what you want to hide. The redacted page is rebuilt from the picture with the boxes burned in. If you need the rest of the text to be searchable afterwards, run the redacted file through OCR PDF; it can only find the text that is still visible.
