Some devices can combine PDFs with software that is already installed, others cannot. Here is what works on each one, without buying anything and without uploading your documents to a website.

On any device: in the browser

Merge PDF works the same way in Chrome, Edge, Firefox and Safari, on a computer, a tablet or a phone. Add the files, drag them into order, click Merge PDFs and save. The files are combined on the device itself, not on a server, so this is also the quickest option on a computer you do not want to install software on.

On a Mac: Preview or Finder

macOS can merge PDFs on its own, in two ways.

  • Finder: select the PDFs, right-click (or Control-click) and choose Quick Actions › Create PDF. The files are combined in the order Finder lists them, so sort the window by name and rename the files first (01, 02, 03…) if the order matters.
  • Preview: open the first PDF, choose View › Thumbnails, then drag the other PDFs from Finder into the thumbnail sidebar at the point where they should go. Use File › Export as PDF to save the result as a new file.

On Windows

Windows has no built-in way to merge PDF files. Microsoft Edge opens and annotates PDFs but cannot combine them, and "Microsoft Print to PDF" prints one document at a time. The free options are a browser-based tool like Merge PDF, which needs no installation, or a desktop program such as the open source PDFsam Basic.

On an iPhone or iPad: the Files app

  1. Open the Files app and go to the folder with the PDFs.
  2. Tap the More button (the circle with three dots), then Select, and tap each file.
  3. Tap More again in the bottom corner and choose Create PDF.

The order is decided by the Files app, so number the file names first (01, 02, 03…) and check the result. To choose the order yourself, open Merge PDF in Safari instead and drag the files into place.

On Android

Android has no built-in PDF merger either. Open Merge PDF in Chrome, tap the box to pick files from your phone or from Google Drive, and save the result to your Downloads folder. If your pages are photos rather than PDFs, convert them first with Images to PDF.

On Linux: the command line

Most distributions include, or can install, one of these:

  • pdfunite first.pdf second.pdf merged.pdf from the poppler-utils package.
  • qpdf --empty --pages first.pdf second.pdf -- merged.pdf from qpdf.

Both run locally. If you prefer to drag and drop, the browser tool works on Linux too.

Before you send the merged file

  • Check the page order by scrolling through the whole file once.
  • Locked PDFs have to be unlocked first; Unlock PDF removes a password you know.
  • The merged file usually keeps the title and author of the first file. Check them with the PDF Metadata Viewer.
